Cantor de Lota Dieciochera 🇨🇱

A single-page, no-dependencies number caller for playing Lota (Chilean bingo). Intended to use for Fiestas Patrias (Chile's Independence Day celebration), but works for any lota night. Draws random numbers from 1 to 90, one at a time, with no repeats until you start a new game.

What it does: 
- "Sacar número" draws a random number from the bombo (1–90) and shows it on a big wooden-ball display
Numbers never repeat within a game: once a number is drawn, it's removed from the pool until the game is reset.
- "Nuevo juego" clears the board and reshuffles the pool for a new round. If a game is already in progress, it asks for a recheck before restarting, so you don't lose a round by accident

Fully self-contained: one HTML file, no build step, no server, no external dependencies besides two Google Fonts
